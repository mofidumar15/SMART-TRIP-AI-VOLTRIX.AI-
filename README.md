# SMART-TRIP-AI-VOLTRIX.AI-

> The Operating System for Group Travel

## Vision

Planning a group trip shouldn't require WhatsApp, Splitwise, MakeMyTrip, and Notes together.

SmartTrip AI brings AI planning, shared itineraries, expense management, group voting, and trip coordination into one platform.

## MVP Features

- Create Trip
- Invite Friends
- AI Itinerary
- Group Voting
- Expense Splitting
- Shared Dashboard

## Tech Stack

- Next.js
- React Native (Expo)
- Supabase
- PostgreSQL
- Vercel
